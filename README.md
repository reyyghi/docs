## Before you ask for help

* Follow the **Installation** page of the script step by step, including the start order in `server.cfg`.
* Read the server console and the F8 client console. Most RHD scripts print a clear message when a dependency or a config value is wrong.
* Check the **Troubleshooting** page of the script, when it has one.
